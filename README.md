# Étapes d'installation et d'exécution

1. Installer les dépendances :
   ```bash
   npm install
   ```

2. Lancer le serveur (API REST + application Vue.js) :
   ```bash
   npm run dev
   ```

3. Ouvrir l'application dans le navigateur :
   ```
   http://localhost:3000
   ```

4. Construire et lancer en mode production :
   ```bash
   npm run build
   npm start
   ```
